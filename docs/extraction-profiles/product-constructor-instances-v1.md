# Owning scalar-product constructor instances

Data-v3 3.91 adds a private owning projection for the original regex-automata
0.4.18 `Match::new<Span>`. The separate
[development selection](../../eval/coverage-development/match-construction/selection.json)
still includes `Match::new<Range<usize>>`; the complete family is unfinished.

The projection checks the complete original source/body roster, nominal fields,
builtin Copy derives, neighboring source closure, actual blanket Into delegation
and reflexive From implementation. Each recursively checked nominal declaration
retains its own source receipt. The graph preserves the whole Span conversion,
saved local, original assertion/panic and complete PatternID/Span result.

Only the immutable `UnitStore::capture_product_constructor` owner grants this
authority. Raw original and copied projected facts remain unavailable. Original
generic spelling, raw receiver observations and deferred source findings remain
intact. The exact private conversion proof supplies concrete receiver evidence.
Ordinary bundle export and caller linking reject these separate instance owners.

`ProductConstructorReplay` reconstructs proof inputs against an independently
inspected original owner under strict policy. Sidecars contain no graph,
certificate or trust flag. Cross-instance document references reject. Transport
continues to use XXH3; this increment adds no SHA computation or serialized lookup
key and preserves existing source identities and historical policies.

`cargo run -p rstyle-ccgraph --example product_instance_probe -- RAW INVENTORY`
checks original/projection negatives, owning production, serialized verification,
strict matcher admission and sidecar replay. It does not establish selected-pair
matching completeness or native execution on captured foreign targets.

Remaining Range chain: bounded consuming formal and no-drop evidence, ordered
endpoint value projections, reverse local From owner/body verification, and an
independently replayed Into-to-From dependency adapter. No Range Copy permission,
general trait dispatch, destructor model or ordinary generic admission is added.
