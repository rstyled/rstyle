complete original success owner contains shared byte slices and scalar or
scalar-Option fields. It proves the actual error's Copy authority, the owner's
complete no-drop source closure and each saved success component's formal origin.

scalar-Option cleanup separately from constructor recognition.

`decoder::LineReader::new_unwrapped`. Its [source-first selection and oracle](../../tests/fixtures/function-families/line-reader/README.md)
require InvalidLength exactly on empty input; otherwise the exact input backing
and `line_width=None`. The complete original owner, derives, imports, neighboring
implementations and possible hidden Drop implementations remain checked. Exact
external macro imports reuse their existing closed census and pinned export
inventory; this grants neither arbitrary macro expansion nor call purity.

and ordinary early returns. Some/None fields require checked scalar Option
semantics. Missing types, origins or source observations fail closed. Historical
profiles lack the new capability.

Stored products/Results, formal product moves, discarded owners, struct update
bases, nested owned carriers, helper export, aggregate `?`, loops and general
match consumption remain unavailable. No destructor or unwind model is inferred.
`LineReader::new_wrapped` additionally needs a checked helper-result transfer,
aggregate propagation, initialized local storage and a field update before
return. Public Decoder constructors require further generic, loop and memory
contracts. This milestone does not establish those callers.

Validation uses real Cargo composition, complete original Cargo contexts,
strict owning-bundle replay and selected identity matching. Independently
specified origin, None, field-slot, saved-payload and historical-policy attacks
are resealed before verification. The native exact-source witness is separate
from cross-target captures; it does not imply native execution on every target.
