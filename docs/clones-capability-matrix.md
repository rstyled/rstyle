Both legacy style and patterns remain operational. The initial corpus alone does
not satisfy retirement: independent quality review, stable review identity,
configuration/suppression/exit compatibility, bounded resource evidence, broader
declared project coverage and docs/skill migration remain required. Existing Go
comparison is unavailable and unverified. Integrated gate results and commits
belong in the lead-owned progress ledger, not inferred from this matrix.

Deep compiler-generated HIR bodies use the shared bundle's version-6 flat preorder
transport, preserving ordinary compiler advisory observations without requiring
strict admission or raising JSON/census limits. Exact field/order roundtrips,
historical formats, malformed rosters and source-free real-Cargo replay are
covered. This transport change grants no new extraction semantics or purity.

The shared core proposer borrows graphs when normalization is disabled. The
238-function rstyle-ccgraph saved-fact comparison retains exactly the same report
while reducing cumulative allocation traffic; it establishes no new proposal
coverage or wall-time speedup. See
[the measured samples](performance/borrowed-proposal-graphs-samples.json).

Compiler advisory also supports the shared changed-file manifest for numeric
diagnostic presentation and finding exits. It reuses completed core diagnostic
paths and shared coverage aggregation; raw diagnostics and fix plans stay intact.
Proposals and invalid suppressions remain global, and selection cannot hide
whole-scope incompleteness. No extra review snapshots, hashes or proofs are needed.

The C26 core planning input seam accepts borrowed facts and exact owner-indexed
rules, retaining group, step and bundle-carrier indices even for identical
source locations/names. Existing core entry points share that implementation.
The opt-in `--compiler-plans` adapter now reuses that seam and the completed
effect graph. Nine real-Cargo cases cover contextual callers, raw-plan policy,
missing/ambiguous inputs and replay. The C25 saved production scope retains
1,568 known owners and gains three independently labeled cross-unit
signature/caller relationships in shared core plans; default advisory/matching
reports remain exactly equal. Its captured inputs remain incomplete; broader
plan quality, external callers and the replacement gate remain pending.
