# eval

Result files for the `patterns` miner. Everything is CSV, regenerated by [`scripts/`](../scripts/README.md); don't hand-edit.

| Path | Produced by | Contents |
| --- | --- | --- |
| `loo/` | `scripts/loo_eval.py` | Leave-one-project-out baseline: `grid.csv` (threshold x min-coverage grid), `loo.csv` (held-out score per project), `noise.csv` (candidates on real crates). |
| `loo_norm_<rules>/` | `scripts/loo_eval.py --normalize <rules>` | Same three files with the canonicalizer on (`all`, `case`, `ctor`, `pred`, `counter+cmp`). `loo/` stays the pinned baseline. |
| `normalize/` | `scripts/normalize_ablation.py` | `ablation.csv`: per-rule ablation at default thresholds; `ablation_<name>.csv` for partial runs. |
| `align/` | `scripts/align_ablation.sh` -> `align_ablation.py` | `labeled.csv`, `variants.csv`, `selectors.csv`, `pair_cov.csv` (from `pair_cov_eval.py`). `pairs.jsonl` (~16 MB) is gitignored. |
| `codenet/` | `scripts/codenet_*.py` | Project CodeNet sample: `s<seed>/` with `shards/`, `pairs.csv`, `manifest.json`, `results_<split>.csv`; `dev_agg.csv` is the seed aggregate. **Gitignored**, regenerate locally. |

Labels come from `rust_refactoring_examples/labels.csv`. Rates in `codenet/results_*.csv` are `flagged / pairs`: recall on positive tiers (`fn_resubmit`, `fn_same_problem`, `fn_identical_problem`), false-positive rate on `fn_cross_problem`.

To reproduce a pinned file, run the script listed above from the repo root; miner outputs are cached under `/tmp/rx_*`, pass `--refresh` to `loo_eval.py` to rebuild.

Strict source-to-pair CCGraph is evaluated separately in
[`ccgraph-v1/`](ccgraph-v1/README.md), with a preregistered source-only corpus,
coverage denominators, exhaustive real-command pair inventories and fixed
matching configurations. Legacy problem/refactoring labels above are not its
clone ground truth.

The separately preregistered coverage/correctness follow-up is
[`ccgraph-v2/`](ccgraph-v2/README.md). Its report preserves missed admission targets,
explicit extraction exclusions and insufficient natural pair-quality evidence.
