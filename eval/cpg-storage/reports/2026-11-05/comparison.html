How to interpret the measurements

  • Shared codecs serialize the same lossless interned arena. Original JSON encodes the producer's JSON trees and decodes into the real CPG Document model. This ranking includes representation differences, with the same original content preserved.
  • Seven measured trials follow one warmup, in randomized format order. Each operation uses a fresh Rust process pinned to CPU 19. The host is shared.
  • Codec timings exclude file I/O, input loading, normalization, and validation. Compressed variants include compression or decompression at Zstandard level 3, using one thread.
  • Original JSON processes documents individually; its times sum codec work and its RSS is the maximum document-stage peak. Shared formats process one whole archive. Data destruction is outside timings. Native zero-copy access and analysis integration are not measured.
  • Stage peak RSS includes the input model or wire buffer. Linux high-water RSS is reset after loading; normalization memory is reported separately.
  • The fresh input came from cpg emit on feat/cpg-document-routes with its recorded local changes. Private Cargo build files are excluded from payload sizes.
